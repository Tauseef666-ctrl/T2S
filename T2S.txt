T2S — Three Friends. One Journey.

A futuristic group study app built with React Native (Expo) for 3 college friends
pursuing Diploma CSE at BTEUP, Semester 3.

GitHub: https://github.com/Tauseef666-ctrl/T2S
Live: http://localhost:8081

---

## Tech Stack

- Framework: React Native with Expo SDK 57
- Routing: expo-router (file-based navigation)
- Language: TypeScript
- Animations: React Native Animated API
- Icons: @expo/vector-icons (Ionicons)
- Gradients: expo-linear-gradient
- Build: npx expo export --platform web
- Server: npx serve -s dist -l 8081

## Screens (12 total)

### Tab Navigation (5 tabs)

1. Home (app/(tabs)/index.tsx)
   - Animated T2S core logo with pulsating animation
   - Floating orbs background
   - Group progress card (68% Semester 3)
   - Exam Prep + Videos quick actions
   - Semester 3 subject cards with progress bars
   - Back Papers subject cards with progress bars

2. Study (app/(tabs)/study.tsx)
   - 6 quick action buttons: Quiz, C Lab, Notes, Timer, Exam Prep, Videos
   - Tab selector: Semester 3 / Back Papers
   - Subject list with progress rings
   - Study tips section

3. Group (app/(tabs)/group.tsx)
   - Group progress stats (Topics Done, Total, Quiz Score)
   - Study groups (OS, DBMS, C Programming)
   - Active challenges with progress bars
   - Shared space (Notes, Tasks, Resources, Leaderboard)

4. AI Chat (app/(tabs)/ai.tsx)
   - Chat interface with typing indicator
   - Pre-built responses for: OS scheduling, SQL JOINs, TCP vs UDP, C pointers, CSS Flexbox
   - Quick prompt chips
   - Smart fallback responses

5. Profile (app/(tabs)/profile.tsx)
   - 4 theme selector (Cyber Night, Obsidian, Midnight Aurora, Minimal Dark)
   - Sound, Notifications, Offline Mode toggles
   - Study Goals with progress bars
   - App info (Version, Build, Board, Course)

### Standalone Screens (7 screens)

6. Subject Detail (app/subject/[id].tsx)
   - Hero section with gradient
   - Unit/topic stats
   - Progress bar
   - Quick actions (Quiz, Notes, Study Timer)
   - Unit cards with progress
   - Video lectures section (top 3 per subject)

7. Unit Detail (app/subject/unit.tsx)
   - Stats (Topics, Questions, Completion %)
   - Topic checklist with completion state
   - Start Study Session button
   - Practice Quiz button

8. Quiz (app/quiz.tsx)
   - 8 MCQ questions across all subjects
   - Difficulty badges (Easy/Medium/Hard)
   - Answer feedback with explanations
   - Progress bar
   - Results screen with score/percentage

9. C Programming Lab (app/lab.tsx)
   - Futuristic terminal UI
   - 4 code examples with output
   - Copy button (with alert confirmation)
   - 5 practice problems with difficulty/points
   - C programming tips

10. Notes (app/notes.tsx)
    - Full CRUD (Create, Read, Update, Delete)
    - Subject picker for new notes (OS, DBMS, Networking, C, Web)
    - Search with real-time filtering
    - Subject filter chips
    - Star important notes
    - Share notes with group
    - Edit existing notes
    - Delete notes
    - Empty state message
    - 5 pre-loaded sample notes

11. Focus Timer (app/study/timer.tsx)
    - Pomodoro modes: Focus (25min), Short Break (5min), Long Break (15min)
    - Animated pulsating circle
    - Progress ring
    - Play/Pause/Reset controls
    - Session stats (Sessions, Minutes, Points)

12. Exam Prep (app/exam.tsx)
    - Tab selector: Expected Questions / Question Papers
    - Subject filter chips
    - 20 expected questions with marks, difficulty, type
    - Expandable answers
    - Stats (Questions, Hard count, Total Marks)
    - 8 question papers with download/open links
    - Links open Google search for BTEUP papers

13. Video Lectures (app/videos.tsx)
    - Subject selector (all 9 subjects)
    - Video cards with thumbnail, title, channel, duration
    - Links open YouTube videos
    - Subject info with video count

## Build & Run

# Install
cd T2SApp && npm install

# Dev server
npx expo start --web

# Production build
npx expo export --platform web

# Serve
npx serve -s dist -l 8081

## Key Features

- Notes CRUD — Create, edit, delete, star, share, search, filter by subject
- Exam Prep — 20 expected questions + 8 question papers with Google search links
- Video Lectures — YouTube links for all 9 subjects
- Quiz — 8 MCQs with difficulty levels, explanations, results
- C Lab — Terminal UI with code examples, copy, practice problems
- Focus Timer — Pomodoro with session tracking
- AI Chat — Smart responses for OS, SQL, Networking, C, CSS
- 4 Themes — Switchable in real-time
- Group Room — Study groups, challenges, shared space
